    OneDrive Daily Backup & Area Manager Sync

    Automated cloud backup without physical USB pen drives

    1

    Branch Daily Routine (End of Shift / Closing)

    Before closing the pharmacy counter each day, the duty pharmacist simply clicks "Daily Backup (OneDrive)". When the save dialog appears, select your branch's local synced OneDrive folder:

    OneDrive - PMG Pharmacy \ PatientCare_Backups \ [Branch_Name]

    Windows OneDrive automatically uploads and synchronizes the .pmgbak file to Microsoft Cloud within seconds.

    2

    How Area Manager Receives Your Daily Backups

    • Area Manager Setup: William Chai creates a master OneDrive folder named PMG_PatientCare_Backups with branch subfolders (e.g., Kota_Sentosa, Branch_02).
    • One-Time Sharing: William shares each branch folder with that branch's Microsoft 365 login. The branch clicks "Add shortcut to My files" in OneDrive web once.
    • Zero USB Dependency: Whenever your branch saves its daily backup, it instantly appears in William's OneDrive. As Area Manager, William can inspect or restore any branch's data directly from his laptop or mobile.
    3

    Medical Data Protection & PDPA Compliance

    All files are bundled in the secure .pmgbak format. Even though files are stored in Microsoft OneDrive cloud, patient health data, NRICs, and lab reports are client-side protected and can only be opened through the authorized PMG Management Hub application.
